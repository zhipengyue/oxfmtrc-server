# 租户与项目权限

## 当前规则

| 角色 | 项目默认 | 素材 / 自定义组件 |
|---|---|---|
| 个人账号 | 仅本人项目；无企业内公开 / 分享 | 仅本人 |
| 企业成员 | 仅本人项目；可设企业内公开或分享给指定成员（查看 / 编辑） | 租户内共享 |
| 企业管理员 | 本人项目默认对成员不可见；可公开或分享。对成员项目可查看并编辑草稿内容，但不能删除、改名/分类、改分享 | 租户内共享与管理 |
| 平台管理员 | 选定租户后，按企业管理员规则监管该租户项目 | 随当前租户切换 |

### 登录身份

- 同一手机号可同时拥有 **个人账号** 与多家 **企业身份**（各自独立密码）。
- 个人登录：手机号 + 密码。
- 企业登录：必须选择企业 + 手机号 + 密码；不选企业无法登录。
- 企业下拉通过公开接口按名称关键字搜索。

### 项目可见性

- `private`（默认）：仅所有者、被分享成员可见；企业管理员对**成员创建**的私有项目仍可监管查看/编辑内容。
- `tenant_public`（企业内公开）：同企业成员可在列表中看到，默认仅查看；需要编辑须单独分享为 `edit`。
- 互联网访问仍走发布流程、版本与访问密码，与企业内公开无关。

### 分享

- 仅所有者可修改公开状态与分享名单。
- 分享权限：`view`（查看）/ `edit`（可改草稿内容）。
- 被分享为 `edit` 仍不能删除项目、改名/分类或改分享设置。

### 管理员对成员项目

可：查看、编辑草稿内容（含页面、数据请求、封面、运行时设置等）。  
不可：删除、改名/分类、改公开与分享、发布版本管理（发布/设默认/删版本仅所有者）。

## 日志管理

企业管理员 / 平台管理员可在「日志管理」查看：

- **登录日志**：登录成功（含 IP / UA）
- **保存日志**：项目草稿、页面、分类、素材、组件、成员、分享、数据请求、运行时配置、文件上传等成功落库操作
- **删除日志**：项目、页面、分类、素材、组件、密钥、文件等删除

顶部提供今日 / 近 7 日 / 近 30 日的登录、保存、删除计数。普通成员无此入口。
